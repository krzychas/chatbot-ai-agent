# chatbot-ai-agent
Chatbot RAG using the Bielik model installed locally,
using the ChromaDB vector database;
app - application,
u - with access for multiple users,
5 - account lockout after 5 failed login attempts,
f - option to add a file to a conversation,
o - OCR,
c - cosine vector comparison method,
d - downloading of conversation history by the user.
